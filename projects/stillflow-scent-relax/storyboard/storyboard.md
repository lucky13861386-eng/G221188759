## 規則自檢

- **連續類型**：S1 全 → S2 全(剖面，連續同場景算一個) → S3 字 → S4 全 → S5 CTA。最多連續 2 個「全」(S1、S2)，之後被「字」打斷 ✓
- **每畫面 ≥1.5 秒**：最短節拍 L5「但嗅覺不一樣」1.5 秒，且屬 S2 連續場景 ✓
- **CTA 時長**：17.3 秒 ≥ 3 秒 ✓
- **剖面佔比**：約 42%（S2）。本支不套嚴格剖面模式（70%），以剖面為主風格 ✓
- **主角一致**：🫧 氣味分子（淡紫＋深光圈）S1 登場、S2 全程、S2 尾進入邊緣系統 ✓

## 需要使用者決定／注意的事

1. **零件要新畫**：頭部／鼻腔／視丘／邊緣系統剖面，零件庫沒有現成的，需照配色新畫（會多花一點製作時間）。
2. **秒數是無聲版（88 秒偏長）**：換成你的真實配音後會重新對齊，通常更短；畫面不變。
3. **情境、emoji 都是扁平向量**（🌙🛋️🍽️🕯️🌿🏠☕），不是真實影片畫面。
4. **出處**：第 4、6、7 句的神經機制說法要確認出處，見 `sources.md`（畫面上沒有數字，風險較低）。
5. 字幕用字以 `inputs/transcript.txt` 為準（第 1 句已採體驗式改寫）。
