# brand.md：STILLFLOW（暖米色・溫柔芳療）

## 配色（覆蓋 design-system.md 的 token）

**這是「亮底」品牌**：底色是暖米色，所以和 design-system 預設（深底）相反——文字用深色、色塊上的字也用深色。下表已照亮底調整。

| Token | 色碼 | 用途 |
|---|---|---|
| `--bg` | `#F6E1C4` | 暖橘米底色（整個畫面；偏暖橘、明亮） |
| `--ink` | `#3B352B` | 主要文字（深暖褐，壓在暖米上對比足夠） |
| `--r1` | `#C98A6B` | 陶土橘：提醒、注意（安全守則用） |
| `--r2` | `#D8B48A` | 奶茶杏：次要強調 |
| `--r3` | `#9B86C9` | 淡紫：**本集主角**、要被注意的那一格（氣味分子、主路線） |
| `--r4` | `#8FA98C` | 柔綠：中性、對照組 |
| `--muted` | `#8A7E6C` | 註腳、出處、次要說明 |
| `--hi` | `#3B352B` | 強調外框／光圈：亮底上改用**深色描邊**（白色在米底看不見） |
| 剖面卡底 | `#EAD6AE` | 剖面卡「窗戶」內的暖色淺底（比 `--bg` 深一點做出層次） |
| 深色卡 | `#3B352B` | CTA 卡等「暖深棕」卡片，配淺色字 `#F3EAD9` |

做 composition 時把上表寫進 `:root`。**亮底的破例**（要在分鏡表／HTML 註明）：
1. **色塊上的文字用 `--ink`（深色）**，不是 `--bg`——因為底色是亮的。
2. **「請看這裡」的強調不用白色**，改用深色細描邊光圈，或 `--r3` 淡紫的呼吸光圈。
3. **剖面卡用暖色淺底 `#EAD6AE`**（不用深黑底，看起來更暖更舒服）；卡內的組織改用**暖棕色系**（頭部 `#CDA87C`、腦區 `#E2C89E`、鼻腔 `#BD9668`），文字與標籤用**深色**；視丘用深綠 `#6F9B84`、邊緣系統與氣味分子用淡紫 `#9B86C9`（冷色點綴，在暖底上會跳出來）。卡片四周留 `--bg`。

## 畫面偏好

- 整體**溫柔**：暖米底、大量留白、淡紫與柔綠點綴，不要高飽和、不要銳利。
- 主軸是**頭部側剖面**：鼻腔 → 嗅覺路徑 → 邊緣系統（情緒・記憶）。這是現成零件庫沒有的，要新畫（照 design-system 第 3 節配色）。
- 氣味分子（主角）用淡紫 `--r3` ＋深色呼吸光圈，從頭到尾同一造型。
- 生活情境用 emoji＋簡單幾何（🌙🛋️🍽️🕯️🌿），**不用寫實照片或影片素材**。
- 不畫產品瓶身、不畫身材焦慮畫面。
