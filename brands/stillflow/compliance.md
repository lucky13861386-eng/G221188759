# 產業守則：STILLFLOW（芳療／身心靈）

產業：身心靈／芳療（精油）

> 從 `.claude/skills/brand-setup/references/industries.md` 的「身心靈」段落複製，再加上芳療與品牌自己的規定。
> **這不是法律意見**；精油／芳療在台灣的宣傳也可能受食品安全衛生管理法、化粧品衛生安全管理法、醫療法規範。正式投放廣告、放客人見證前，請找熟悉法規的人確認。

## 1. 常見相關法規

醫療法（非醫療機構不得做醫療廣告）；心理師法（心理諮商、心理治療是心理師的業務）；化粧品衛生安全管理法（精油作為化粧品用途時）；食品安全衛生管理法（可食用相關產品時）；公平交易法（不實廣告）。

## 2. 不能說

1. **醫療或心理治療效果**：治療、改善或緩解任何疾病或症狀——例如治療失眠、改善失眠、抗憂鬱、抗焦慮、消炎、止痛、降血壓、提升免疫。
2. 沒有心理師證照時，用「心理諮商」「心理治療」「諮商師」描述服務 → 改用「陪伴」「引導」「對談」「身心調理」「自我覺察」。
3. **改變身體器官、組織、生理功能**：排毒、淨化、促進代謝、增強免疫、抗老。
4. **保證結果或預測**：保證有效、一定放鬆、保證改善、改運、轉運、招財、預測健康。
5. 用恐懼推銷：不用就會怎樣、業障、別人害你。
6. 星座、塔羅、能量、測驗**只能當「認識自己的有趣角度」**，不能說它能診斷身體或心理狀況。

## 3. 可以說

- **講知識，不講療效**：講「氣味訊號在大腦裡怎麼走」是衛教；講「這支精油治好你的失眠」就是違規宣稱。
- 體驗式說法：「很多人覺得比較容易放鬆」「幫你營造放鬆的氛圍」「照顧自己的小儀式」——描述體驗與氛圍，不是保證生理療效。
- 有研究支持的一般知識（例：嗅覺與情緒記憶的神經路徑），一樣要在 `sources.md` 列出處。
- 安全提醒是加分：稀釋、不內服、孕婦嬰幼兒寵物要小心、長期不適請就醫。

## 4. 這個品牌自己的規定

1. 影片講知識，產品／服務只出現在 CTA 之後的測驗與諮詢，不在影片中段推銷。
2. 不給特定精油的「療效對應表」（哪支治哪個症狀）。
3. 不出現特定品牌名稱。
4. 語氣是「降低焦慮、提供判斷依據」，不製造恐慌、不羞辱。
