# 產業守則：StillFlow（身心靈／精油芳療 × 傾聽陪伴）

產業：身心靈（精油／芳療入口）＋情緒陪伴

> 從 `.claude/skills/brand-setup/references/industries.md` 的「身心靈」複製，再加上精油芳療與本品牌自己的規定。
> 不是法律意見；正式投放廣告前請找熟悉法規的人確認。

## 1. 法規重點（身心靈）

- **不宣稱醫療或心理治療效果**：不說治療憂鬱、焦慮、恐慌、失眠、創傷；不暗示可以取代就醫或吃藥（醫療法）。
- **沒有心理師證照，不用「心理諮商」「心理治療」「諮商師」**描述服務（心理師法）。
  → 用「傾聽」「陪伴」「引導」「對談」「自我覺察」。
- **不保證結果、不預測**：改運、轉運、保證放鬆、預測健康（公平交易法：不實廣告）。
- **不用恐懼推銷**：不做會有厄運、業障、別人害你。

## 2. 精油／芳療特別規定

- **精油不是藥**：不說精油能「治療／改善／舒緩／預防」任何疾病或症狀（焦慮、失眠、頭痛、經痛、感冒、發炎…）。
  → 只講**體驗**：「很多人覺得聞了比較放鬆」「給自己一個停下來的儀式」，不是「治好○○」。
- 不說精油「抗菌、消炎、排毒、助眠、療癒」等功效用語。
- **安全提醒**（講到實際使用時，說明文字或畫面要帶一句）：
  - 精油需稀釋，**原液不直接塗抹皮膚**；避免接觸眼睛。
  - **孕婦、嬰幼兒、蠶豆症（G6PD）、寵物、過敏體質**使用前先諮詢專業。
  - 柑橘類等有**光敏性**，塗抹後避免曬太陽。
  - 不建議內服。

## 3. 這個品牌自己的規定

1. **影片講陪伴與放鬆的體驗，不推銷精油功效**。精油產品不出現在影片中段推銷，只在私訊／陪伴之後依需求介紹。
2. 講到情緒、睡不好，用「很多人會」「有研究發現」，不說「一定」「保證」。
3. 傾聽陪伴**不是**心理諮商／治療；說明文字固定加一句：「長期睡不好、情緒低落，請找醫師或心理師聊聊。」
4. 不羞辱累壞的人、不製造焦慮；語氣是「先停下來，好好喘口氣」。
5. 嗅覺、呼吸、神經系統的研究數字都要有出處（例：衛福部、食藥署、相關期刊的公開資料）。
